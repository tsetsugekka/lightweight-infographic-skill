# Maintenance

- Keep SKILL.md authoritative for behavior; keep the English, Chinese and Japanese READMEs aligned with it.
- Preserve the distinction between a visual style and a fixed template. Examples never establish product facts or publication authority.
- Before committing, inspect the current branch, working tree and staged changes. Commit only the requested work; never include credentials or private records.
- Use the established main branch for authorized publication. Do not create or reuse a temporary release branch without a request.
- Push when the user requests publication or standing authorization applies. Maintain accurate repository description and topics, and read them back after changes.
- Validate skill frontmatter, UI metadata, local links and public-safe content before publication. Do not add a license unless explicitly requested.
